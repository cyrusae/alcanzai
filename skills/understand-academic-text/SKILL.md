# Understand Academic Text

## Reading strategy

Process papers in this order for efficiency:
1. **Abstract** — main claim, method, key result
2. **Introduction** — problem statement, gap in literature, contribution
3. **Conclusion/Discussion** — what was found, implications, limitations
4. **Methods** — how they did it (skim unless methodology is the point)
5. **Results** — what the data showed

## What to extract from each section

**Abstract**: One-sentence claim, method keyword, main quantitative result if present.

**Introduction**: The gap being filled ("Previous work X, but Y is unknown"). The specific contribution ("We show/propose/demonstrate..."). Any explicit scope limitations.

**Methods**: Study design, sample/dataset, analysis technique. Note any unusual choices.

**Results**: Primary finding (numerical where possible), direction of effect, statistical confidence.

**Conclusion**: Authors' interpretation, stated limitations, future work they suggest.

## Section patterns by paper type

**Empirical**: IMRaD structure (Introduction, Methods, Results, Discussion). Key content in Results and Discussion.

**Theoretical**: Argument builds across sections. Introduction states thesis; body develops it; conclusion asserts it's been proved.

**Review/Survey**: Structure is taxonomic. Introduction frames the landscape; body organizes existing work; conclusion identifies gaps.

**Position paper**: Often shorter, structured as argument. Intro states position; body provides evidence; conclusion urges action.

## Common navigation signals

- "We argue/show/demonstrate/propose" → thesis location
- "Previous work has / Prior to this" → gap location
- "In summary/To summarize/In conclusion" → key finding location
- "One limitation/Future work should" → scope location

## When text is dense or long

Focus on: first sentence of each paragraph (usually the topic sentence), any numbered lists, section headers, figure captions.

Skip: Related work section (unless building citation graph), acknowledgments, appendices on first pass.
