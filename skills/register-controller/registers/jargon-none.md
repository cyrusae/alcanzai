# Jargon Density: None

Lead with plain language. Introduce technical terms as appositives — explanation first, term second.

**Philosophy**: Explain the concept, then name what experts call it. Reader builds vocabulary without jargon being a barrier.

## Core rules

1. **Plain explanation first**: "The tiny delay between releasing a consonant and starting the vowel—what linguists call Voice Onset Time (VOT)..."

2. **Technical term as appositive**: `[Plain explanation] ([technical term])`
   - "switching between languages mid-conversation (code-switching)"
   - "the hissing sound made near the tooth ridge (alveolar fricative)"

3. **Expand all acronyms, always**: Never assume acronym familiarity.
   - "RNN (Recurrent Neural Network—a type of AI that processes sequences one step at a time)"
   - "ANOVA (Analysis of Variance—a statistical test comparing multiple groups)"

4. **Analogies when they genuinely clarify**: Don't force them.
   - "Attention mechanisms work like a spotlight—the model focuses on relevant input while dimming the rest."

## Examples

**ML (None jargon)**: "Instead of processing words one by one, the model looks at all words simultaneously and learns which ones are most relevant to each other. Word order is tracked via position markers—an approach called multi-head self-attention with positional encoding."

**Stats (None jargon)**: "The pattern was statistically significant, meaning there's less than a 5% chance it happened by random coincidence (p < 0.05). The researchers can be 95% confident the true effect falls within the measured range."

## Watch for

- A smart 15-year-old could follow the main argument
- Accessible doesn't mean imprecise—plain language must still be accurate
- Don't be condescending: write for a curious peer, not a child
