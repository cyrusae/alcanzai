# Register Controller

Register is specified as three independent axes. Load exactly one file per axis, then apply all three settings simultaneously to your synthesis.

## Jargon density

| Setting | When to use | File |
|---------|-------------|------|
| `none` | Smart non-expert reader; new field; partner-shareable | [registers/jargon-none.md](registers/jargon-none.md) |
| `selective` | Learning the field; notes for future self; refreshing after hiatus | [registers/jargon-selective.md](registers/jargon-selective.md) |
| `heavy` | Active expert; dissertation notes; rapid scanning | [registers/jargon-heavy.md](registers/jargon-heavy.md) |

## Sentence structure

| Setting | When to use | File |
|---------|-------------|------|
| `conversational` | Personal notes; burnout recovery; maximum readability | [registers/structure-conversational.md](registers/structure-conversational.md) |
| `mixed` | Standard synthesis; balanced professionalism | [registers/structure-mixed.md](registers/structure-mixed.md) |
| `formal` | Dissertation material; formal literature review; publication notes | [registers/structure-formal.md](registers/structure-formal.md) |

## Explanation depth

| Setting | When to use | File |
|---------|-------------|------|
| `hand-holding` | New field; gap-year refresh; want to understand the why | [registers/depth-hand-holding.md](registers/depth-hand-holding.md) |
| `balanced` | Standard academic detail; familiar but not expert | [registers/depth-balanced.md](registers/depth-balanced.md) |
| `assume-knowledge` | Active research; quick reference; expert scanning | [registers/depth-assume-knowledge.md](registers/depth-assume-knowledge.md) |

## Default register

If no register is specified: `selective` jargon + `mixed` structure + `balanced` depth.

## Application

After loading the three register files, apply their combined guidance to every section of the synthesis. Jargon affects which terms you explain. Structure affects sentence-level construction. Depth affects how much you explain the *why* behind methods and findings.
