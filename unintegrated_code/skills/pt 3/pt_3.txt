## Your XML vs JSON Intuition is Correct

**You're right to stick with pseudo-XML.** Here's why:

**JSON parsing is brittle:**
```json
{
  "summary": "This paper introduces transformers, which are really
  "key_concepts": ["transformers"]
}
```
One missing quote or comma → entire parse fails. You get nothing.

**XML/tag parsing is forgiving:**
```xml
<summary>
This paper introduces transformers, which are really
cool and revolutionary.
<key_concepts>
transformers, attention-mechanism
</key_concepts>
```
Even with messy formatting or a missing close tag, regex extraction can still recover most content.

**Your current approach (v0.1.5):**
```python
def extract_tag(tag_name, text):
    pattern = f"<{tag_name}>(.*?)</{tag_name}>"
    match = re.search(pattern, text, re.DOTALL)
    return match.group(1).strip() if match else ""
```

This is **extremely robust**. Even if Claude messes up formatting, you get partial results rather than catastrophic failure.

**My recommendation: Keep pseudo-XML, extend it for citation analysis:**

```xml
<summary>
3-4 sentences here...
</summary>

<why_you_cared>
2-3 sentences here...
</why_you_cared>

<key_concepts>
concept-1, concept-2, concept-3
</key_concepts>

<memorable_quote>
"Exact quote from paper"
</memorable_quote>

<citation_analysis>
<citation>
<text>Vaswani et al. (2017) - Attention Is All You Need</text>
<role>foundational</role>
<importance>high</importance>
<summary>Introduces transformer architecture this work extends</summary>
</citation>

<citation>
<text>Bahdanau et al. (2014) - Neural Machine Translation</text>
<role>contrasting</role>
<importance>medium</importance>
<summary>Prior attention mechanism this improves upon</summary>
</citation>
</citation_analysis>
```

**Parsing strategy:**
```python
# Easy: same pattern you already use
citations = []
citation_blocks = re.findall(r'<citation>(.*?)</citation>', response, re.DOTALL)

for block in citation_blocks:
    citation = {
        'text': extract_tag('text', block),
        'role': extract_tag('role', block),
        'importance': extract_tag('importance', block),
        'summary': extract_tag('summary', block)
    }
    citations.append(citation)
```

**Graceful degradation:** If Claude only provides `<text>` and `<role>` but forgets `<summary>`, you still get partial data. With JSON, you'd get nothing or have to write complex error recovery.
