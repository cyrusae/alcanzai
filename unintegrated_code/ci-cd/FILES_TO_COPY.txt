## SETUP INSTRUCTIONS

1. Copy all files above into your project

2. For .devcontainer/postCreateCommand.sh:
   chmod +x .devcontainer/postCreateCommand.sh

3. Update pyproject.toml with:
   [project.scripts]
   alcanzai = "paper_library.cli:cli"
   
   [project.optional-dependencies]
   dev = [
       "pytest>=8.0.0",
       "black>=24.0.0",
       "ruff>=0.6.0",
       "pre-commit>=3.0.0",
       "pyyaml>=6.0",
   ]

4. Delete old test files:
   rm test_arxiv.py test_grobid.py test_synthesis.py test_markdown.py test_pipeline.py

5. Run quickstart:
   bash quickstart.sh

6. OR manually:
   uv sync --all-extras
   pre-commit install
   source .venv/bin/activate
   pytest tests/ -m "not integration"
